THIRANEX TASK 1 - ACCESSIBLE MULTI-PAGE PORTFOLIO

FILES
- index.html: Home page
- about.html: About page
- projects.html: Project listing
- contact.html: Contact page with accessible front-end validation
- css/style.css: Responsive styling
- js/script.js: Mobile navigation, current year and demo form behavior

RUN LOCALLY
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Navigate through the Home, About, Projects and Contact links.

CUSTOMIZE BEFORE SUBMISSION
- Replace "Alex Morgan" with your name.
- Update the introduction, skills, project descriptions and contact details.
- Add your own project links and real images with descriptive alt text where needed.
- The contact form is a front-end demo only. To receive submissions, connect a backend or a form service.

ACCESSIBILITY / QUALITY CHECKS
- Use keyboard Tab and Shift+Tab to move through links and form controls.
- Press Enter/Space on the mobile navigation button.
- Check that the skip link appears when focused.
- Run Lighthouse in Chrome DevTools for Accessibility, SEO, Best Practices and Performance.
- Check color contrast and test at mobile widths.

The project is designed with semantic landmarks, a skip link, visible focus styles, labels,
native form validation, responsive layouts, reduced-motion support and page-specific metadata.
A perfect Lighthouse score cannot be guaranteed on every browser/device; run the audit after
replacing the sample content and assets.
